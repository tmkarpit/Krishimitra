# KrishiMitra — AI crop advisor for Indian farmers

SIH 2025 · Problem Statement 25030 "AI-Based Crop Recommendation for Farmers" · Team RUBIX (109218)

A farmer picks their language, marks their land on a map, and gets AI guidance on which crop to grow, fertilizer doses, a dated work calendar, weather alerts, mandi prices, crop-disease diagnosis from a photo, and government schemes — by text and by voice, in 11 Indian languages.

```
app/            React Native + Expo (SDK 58, Expo Router, TypeScript) — runs in Expo Go
supabase/       Postgres schema + RLS + seed data, Edge Functions (Deno/TypeScript)
ml-service/     Optional FastAPI + XGBoost crop model
KRISHIMITRA_MASTER_PROMPT.md   Product spec
```

## How it works

| Feature | Where | Data source |
|---|---|---|
| Language choice (en, hi, mr, pa, gu, bn, ta, te, kn, ml, or) | `app/src/locales`, `app/src/app/language.tsx` | — |
| Phone OTP login + guest mode | Supabase Auth | — |
| Mark land: tap corners, walk the boundary, or drop a pin | `app/src/app/field/new.tsx` | Phone GPS + geocoder |
| Soil analysis | `analyze-field` | SoilGrids (ISRIC) → state soil fallback → Soil Health Card scan / manual entry |
| Weather + last-year climate | `analyze-field` | Open-Meteo (no key) |
| Crop recommendation | `recommend-crops` | Rule-based suitability (+ XGBoost if deployed) → mandi prices → Gemini explains in the farmer's language |
| Season plan: fertilizer + work calendar | `crop-plan` | Deterministic fertilizer math + AI guidance |
| AI chat with photo | `chat` | Gemini, with farm context |
| Disease diagnosis from photo | `diagnose-disease` | Gemini vision |
| Soil Health Card OCR | `read-soil-card` | Gemini vision |
| Voice in / out | `speech` + phone TTS | Gemini transcription + phone voice (Sarvam AI optional) |
| Mandi prices | `market-prices` | data.gov.in Agmarknet |
| Weather alerts | `weather-alerts` (cron) | Open-Meteo |
| Government schemes | `schemes` table | Seeded (8 central schemes, en + hi) |
| Crop value from photos (land type, stage, health, ₹ value) | `estimate-crop-value` | Gemini vision + regional yield × area × mandi/MSP price |
| Sell produce directly to buyers (call / WhatsApp / offers) | `produce_listings`, `listing_enquiries` | Farmer-entered; phone shown only to signed-in users |
| Seed & input shop (cash on delivery) | `input_products`, `input_orders` | Registered sellers + sample catalogue; prices/stock enforced by DB triggers |

The fertilizer numbers are never generated by the AI — they come from `supabase/functions/_shared/agro.ts`, which is unit-tested.

## Run it locally

Prerequisites: Node 20+, Docker Desktop, the Expo Go app on your phone.

### 1. Backend (Supabase)

```bash
npx supabase start                 # starts Postgres, Auth, Storage, Edge runtime; applies migrations + seed
cp supabase/functions/.env.example supabase/functions/.env   # add GEMINI_API_KEY (free) at minimum
npx supabase functions serve --env-file supabase/functions/.env
```

`supabase start` prints an **API URL** and **anon key** — you need both for the app.

Local test login: phone `9999900000`, OTP `123456` (set in `supabase/config.toml`). Or tap "Continue without number".

### 2. App

```bash
cd app
cp .env.example .env
# EXPO_PUBLIC_SUPABASE_URL  = http://<your-computer's-LAN-IP>:54321   (not 127.0.0.1 — the phone must reach it)
# EXPO_PUBLIC_SUPABASE_ANON_KEY = <anon key from supabase start>
npm install
npx expo start
```

Scan the QR code with Expo Go (Android) or the Camera app (iOS). Phone and computer must be on the same Wi-Fi.

### 3. Tests

```bash
cd app && npx tsc --noEmit && npx expo lint
cd supabase/functions && npx deno test _shared/agro_test.ts && npx deno check */index.ts
```

## Deploy to Supabase cloud

```bash
npx supabase login
npx supabase link --project-ref <ref>
npx supabase db push                      # migrations
# run supabase/seed.sql in the SQL editor (or: psql "$DB_URL" -f supabase/seed.sql)
npx supabase secrets set --env-file supabase/functions/.env
npx supabase functions deploy
```

Then in the dashboard:
- **Auth → Providers → Phone**: enable and connect an SMS provider (Twilio / MSG91 / Vonage). Add test numbers for demos.
- **Auth → Settings**: enable anonymous sign-ins (guest mode).
- **SQL editor**: run `supabase/cron.sql` after filling in the project ref and `CRON_SECRET` (weather alerts every 3 hours).

## API keys — the whole stack runs free

| Key | Needed for | Cost |
|---|---|---|
| `GEMINI_API_KEY` | AI advice, crop plans, chat, disease photos, soil-card reading, voice input | **Free** — create at https://aistudio.google.com/apikey with a Google account, no card |
| `DATA_GOV_IN_API_KEY` | Live mandi prices (also improves profit estimates) | Free — data.gov.in account |
| `SARVAM_API_KEY` | Better voice in/out for languages the phone can't speak | Optional (free starter credits) |
| `ANTHROPIC_API_KEY` + `AI_PROVIDER=anthropic` | Use Claude instead of Gemini | Optional, paid |
| `ML_SERVICE_URL` / `ML_SERVICE_TOKEN` | XGBoost model blended into the ranking | Optional |
| `CRON_SECRET` | Protects the weather-alerts job | Any random string |

Weather (Open-Meteo), soil (SoilGrids), maps (Expo Go) and spoken answers (phone voice) need no key. Supabase's free plan covers the database, login and functions.

**Free-tier notes (Gemini):** requests are rate-limited per minute and per day; when the main model (`gemini-3.8-flash`) is busy the server retries on `gemini-3.5-flash-lite`. Google may use free-tier prompts and photos to improve its products — fine for a hackathon demo, but switch to a paid tier before handling real farmers' data.

## Known limits

- **Soil data**: SoilGrids has no coverage for much of India, so many fields start from a state-level soil estimate (labelled "Regional estimate"). Scanning the farmer's Soil Health Card replaces it with real values.
- **Crop names** are stored in English, Hindi and Marathi; AI-generated screens return names in every language. Scheme text is in English and Hindi.
- **Push notifications** are not available in Expo Go (SDK 53+); alerts show in the app. A development build (`eas build --profile development`) enables push.
- **Prices and profits** are estimates; the app says so and points farmers to their KVK.
- **UI** uses a placeholder theme (`app/src/theme.ts` + `app/src/components/ui.tsx`) so the final design can be swapped in without touching screens' logic.
